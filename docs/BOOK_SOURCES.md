# 书源与在线阅读

ReadCLI 在终端内支持导入 Legado JSON 书源、管理书源、搜索小说、浏览目录和在线阅读。解析器由 Go 实现，参考 Legado 的格式与行为；兼容范围见下文，不要求安装 Android 或运行 Legado。

## 使用流程

1. 在书架按 `S` 打开书源管理，按 `i` 输入本地 JSON 路径或 JSON 下载链接，也可将 JSON 文件直接拖入终端；自动处理终端给空格、括号等字符添加的路径转义。支持单个书源、合集以及 JSON 字符串形式的规则块。相同 `bookSourceUrl` 会更新已有定义。非文字或仅发现书源会保留但停用。
2. 上下键选择书源，空格或 `e` 启用/停用；`d` 移除（需 `y` 确认）。移除书源保留书架和缓存。
3. 管理页按 `/` 搜索当前源，按 `s` 搜索所有已启用书源。书架也可直接按 `s` 在线搜书。
4. 搜索结果按 `n/p` 翻页，`/` 换关键词，`r` 重试，`e` 查看各书源的完整错误。按 Enter 加载目录和第一章并加入书架。每个失败源单独显示错误，最多并发请求四个源。
5. 阅读页沿用 `j/k` 翻页、`←/→` 切章、`m` 目录、`g` 章节/百分比跳转、`s/B` 书签、`a` 对齐、`,` 阅读设置。到达章节末尾后继续翻页会加载下一章。`R` 刷新在线目录；正文搜索 `/` 只搜索当前已加载章节。
6. `Esc` 取消加载，`q` 返回书架。目录和正文按需缓存，已缓存章节可离线重开。切换章节和退出时保存章节链接、章内位置；调整窗口宽度保留章内进度。

源仓库提供 [单个书源列表](https://www.yckceo.com/yuedu/shuyuan/index.html) 和 [合集列表](https://www.yckceo.com/yuedu/shuyuans/index.html)。导入时使用详情页提供的 **JSON 下载链接**，列表或详情 HTML 网页本身不能作为书源导入。仓库中 [示例定义](../examples/book-source.json) 默认停用，需替换成实际站点地址与规则。

## 更换书源

在书架选中在线书籍，或阅读在线书籍时，按大写 `C` 搜索其他版本。列表逐项显示书源、作者和最新章节；聚合书源的最新章节前缀可能包含站点名，可据此区分同一书源内的不同站点。书架右侧也会显示当前书源及更新信息。

用上下键或 `j/k` 选择，`n/p` 翻搜索页，`r` 刷新，Enter 加载所选版本的目录和正文。确认页会显示原源、新源、定位后的章节及章内进度；无法匹配同名章节时，会提示按旧章节序号近似定位。检查后按 Enter 或 `y` 确认，`Esc/q` 返回候选列表。

候选列表或加载过程中按 `Esc/q` 取消换源，返回原来的书架或阅读界面。新目录与正文加载成功且确认之前，原书和阅读进度都会保留。确认后迁移阅读进度及匹配的书签；未匹配书签仍会保留，可能需要回原源查看。小写 `c` 仍用于切换阅读颜色。

## 登录

书源管理选择目标后按 `L`，按 Tab 或上下键切换字段，Enter 登录。密码隐藏显示，提交或取消后清空输入。`X` 退出登录。

- 大灰狼融合/聚合书源：提供邮箱和密码登录，使用书源 API 获取会话令牌。
- 其他需要会话的文字书源：可以填入从对应网站取得的 Cookie。
- 不执行登录页中的注册、充值、购买或任意按钮；Android 专有登录界面、验证码及浏览器交互尚未移植。

`sessions.json` 保存会话 Cookie、登录令牌、书源及书籍脚本变量和设备标识，不保存登录时输入的明文账号密码；文件权限为仅当前用户可读写。会话过期时请重新登录。登录后的请求使用同一 Cookie 会话。

## 正文净化与替换

在线正文会自动移除常见 HTML 标签，将 `<p>`、`<div>`、`<br>` 转为段落或换行，处理 HTML 实体并去掉 script/style 内容。之前缓存中残留的标签在重新打开章节时同样处理，无需删除缓存或重新下载。

书架、在线阅读页或书源管理页按大写 `P` 打开净化配置，按 `i` 输入 Legado 净化规则 JSON 下载链接或本地文件路径（支持拖入文件），Enter 导入。规则与书源分别管理。配置页可以查看规则文件路径和启用数量，按 `r` 重新读取本地编辑结果，`Esc/q` 返回；从在线阅读进入时，返回会从原始缓存重新应用规则，并尽量保持章内位置。打开书籍或切换章节也会读取最新规则。

文件保存在同一个数据目录：

```text
~/.readcli/replace_rules/
  main.json             # 本地主配置，初始化为 []，可直接编辑
  imports/
    名称-来源摘要.json   # 每个导入来源单独保存
```

重复导入同一个链接或路径只更新其对应文件，其他导入文件与 `main.json` 不受影响。导入组按文件名排序，每组按 `order` 稳定排序；`main.json` 最后执行，便于补充个人替换。文件内容是标准 JSON 数组（也接受单条对象），不能带 JSON 注释。示例：

```json
[
  {
    "name": "去除固定推广文字",
    "isEnabled": true,
    "isRegex": false,
    "pattern": "请收藏本站",
    "replacement": "",
    "scopeContent": true,
    "scopeTitle": false,
    "order": 1
  }
]
```

支持普通替换、正则捕获组替换、前后顾判断、`@js:` 逐匹配替换，以及 `scopeTitle` / `scopeContent`、书名或书源地址的 `scope` / `excludeScope`。JavaScript 的 `result` 是当前匹配文本；运行在独立的受限环境中，不提供 Android/Java 宿主接口。正则和脚本有执行时间限制，错误会提示并保留原文。配置页按 `e` 查看完整错误，用上下键滚动，`Esc/q` 返回文件列表。净化规则目前应用于在线正文和章节标题；原始书源规则、目录与正文缓存保持可恢复，停用规则或修改后重新打开章节即可重新处理。

## 规则兼容范围

支持的主要能力：

- CSS / `@css:`，Legado 常见 `class.`、`id.`、`tag.` 链式选择、索引与 `@text/@html/@href` 等字段提取。
- JSONPath、`@json:`、XPath / `@xpath:`。
- `##` 正则替换、`||` 候选规则、`&&` 合并规则。
- `@js:` / `<js>` JavaScript、`jsLib` 和 `{{...}}` 模板，提供受限的 `java`、`source`、`cookie` 宿主方法。
- 搜索关键词和页码模板、相对 URL、GET/POST、请求头、表单/JSON 请求体、Cookie、字符集解码、data URI。
- 目录和正文分页、去重、循环检测与响应大小/分页数量限制。

不等同于 Legado 的全部 Android 运行环境。WebView、Rhino/Java 类调用、音频、漫画、发现频道、复杂交互验证及未实现的宿主方法会明确报错。Go 正则语法与 Java 正则不同，例如部分回溯引用或后行断言需要调整规则。实际能否使用还取决于目标网站可用性和账号权限。

## 本地数据

书源和阅读数据统一使用原有配置目录（macOS / Linux 默认 `~/.readcli/`，Windows 默认 `%USERPROFILE%\.readcli\`，可用 `READCLI_DATA_DIR` 覆盖）：

- `config.json`：阅读样式等设置。
- `book_sources.json`：完整书源定义和启用状态；导入后不再依赖原 JSON 文件或下载链接。
- `sessions.json`：登录会话、设备标识及书源/书籍脚本变量。
- `online_cache/`：按书源与书籍区分的目录、章节缓存。
- `replace_rules/main.json` 与 `replace_rules/imports/`：本地及导入的净化替换规则。
- `bookshelf.json`、`progress.json`、`bookmarks.json`：同时保存本地与在线书籍状态。

本地 TXT / EPUB 阅读流程保持兼容；在线书籍在书架显示为 `ONLINE`。

### 整目录备份与恢复

1. 正常退出 ReadCLI，确保最新进度和会话已保存。
2. 备份整个 `.readcli` 文件夹。如果设置了 `READCLI_DATA_DIR`，备份该变量指定的文件夹。
3. 恢复时先关闭 ReadCLI，用备份文件夹的全部内容替换当前数据目录的内容。`config.json` 和 `book_sources.json` 应直接位于数据目录下，不要多嵌套一层 `.readcli`。
4. 重新启动后自动加载设置、书源、启停状态、书架、进度、书签、登录会话和已缓存章节，无需重新导入书源。目录可以搬到新位置，启动时用 `READCLI_DATA_DIR` 指向它。

替换完整文件夹后需要重新启动，运行中的程序不会监视书架或书源文件变化；净化规则可以在 `P` 页面重新加载。备份包含可用的登录会话，应妥善保管；服务端已过期的会话仍需重新登录。在线缓存只包含已经加载的章节，其余章节继续通过书源获取。

本地 TXT / EPUB 原文件仍保留在导入时的位置，不会复制到数据目录中；这类文件需要另外备份，换位置后重新导入。

## 实现结构

Legado 的处理顺序对应本项目的 `booksource` 包：`searchUrl + ruleSearch` 生成书籍列表，`ruleBookInfo` 读取详情与目录地址，`ruleToc` 提取章节，`ruleContent` 加载正文。`rules.go` 与 `js.go` 负责字段规则，`client*.go` 负责请求及分页，`session.go` 负责会话，`store.go` 保存定义和缓存。

`reader.OnlineReader` 只持有当前章节与完整目录，网络操作由 `core/online.go` 在后台完成。页面切换或取消会作废旧请求，下载完成后仅当前请求可更新界面；阅读进度使用章节链接与章内比例，避免依赖尚未下载的全书行号。
